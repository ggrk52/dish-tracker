## ✨ Главные фишки

- 🪟 **Эстетика Apple VisionOS & Glassmorphism**: Парящий стеклянный док навигации (Floating Dock), мягкое размытие фона, сочная палитра современного цветового пространства OKLCH и живая неоновая подсветка активного дежурного.
- ⚡ **Zero Dependencies (0 npm-библиотек)**: Чистый Vanilla JavaScript и семантичный CSS3. Никаких React, Webpack или тяжелых зависимостей. Приложение весит считанные килобайты и открывается молниеносно на любом смартфоне или планшете.
- 🔄 **Micro-Diffing & ETag 304**: Умное обновление интерфейса без мерцания экранов и лишней перерисовки DOM. Локальный сервер отвечает за доли миллисекунды, передавая **0 байт** тела ответа, если данных нет новых.
- 🔊 **Встроенный аудио-синтезатор (Web Audio API)**: Тактильные щелчки переключателей, всплывающий пузырьковый звук и победный мажорный аккорд (C5–E5–G5–C6) синтезируются прямо в браузере «на лету» без скачивания MP3-файлов.
- 📱 **Честный PWA и работа офлайн**: Добавляется на главный экран iPhone или Android как нативное приложение без рамок браузера. Service Worker сохраняет все ассеты для мгновенного запуска.
- ☀️ **Screen Wake Lock**: Режим предотвращения засыпания экрана — незаменим для настенного планшета или старого смартфона, закрепленного на кухне в виде постоянного табло.
- 🔐 **Простые семейные роли и PIN-коды**: Любой гость или домочадец может смотреть историю и рейтинг. Но отметить закрытие смены, поменяться местами или переставить очередь могут только авторизованный дежурный или Администратор.
- ☁️ **Гибридная синхронизация**: Работает в локальной сети Wi-Fi (Raspberry Pi, Linux-сервер, домашний ПК, Docker) либо подключается к бесплатному облаку (Cloudflare Workers KV или Google Firebase) для обновления через мобильный 4G/5G в любой точке города.
- 📊 **Дайджест в один клик и экспорт в CSV**: Кнопка «Поделиться» генерирует аккуратный форматированный отчет с эмодзи-медалями для семейного чата в Telegram или WhatsApp, а журнал истории выгружается в CSV для Excel или Google Таблиц.

Центральный экран приложения:

## 🚀 Как запустить дома

Серверная часть спроектирована максимально экономно: она работает на стандартной библиотеке Python или Node.js (без `pip install` и внешних пакетов), держит состояние в оперативной памяти для моментальных ответов и бережёт MicroSD-карты в Raspberry Pi за счёт атомарной записи.

### За что вам скажет спасибо домашний сервер:
- **Кэширование в RAM**: Запросы на чтение (`GET /api/state`) отдаются прямо из памяти без лишних обращений к диску.
- **Поддержка ETag и 304 Not Modified**: Если состояние очереди не изменилось, сервер возвращает пустой ответ `304` за **< 1 мс**, передавая **0 байт** тела.
- **Сжатие Gzip на лету**: Статические файлы и JSON сжимаются автоматически, экономя мобильный трафик.
- **Атомарная запись**: Сохранение в `data.json` происходит через временный файл с блокировкой (`threading.Lock`), исключая повреждение данных при внезапном отключении питания.

### Вариант 1: Raspberry Pi / Linux (Systemd-сервис 24/7)

Рекомендуемый способ для домашнего микрокомпьютера — работает непрерывно и сам поднимается после перезагрузки.

#### 1. Клонирование репозитория
```bash
cd ~
git clone https://github.com/ваш-логин/dish-tracker.git
cd dish-tracker
```

#### 2. Пробный запуск
```bash
python3 server.py
# Сервер запустится на http://0.0.0.0:8080
```

#### 3. Настройка автозапуска в Systemd
Создайте файл службы:
```bash
sudo nano /etc/systemd/system/dish-tracker.service
```

Вставьте конфигурацию (замените `pi` на ваше имя пользователя в системе, если оно отличается):

```ini
[Unit]
Description=Dish Tracker PRO - Умный трекер и график дежурств
After=network.target

[Service]
Type=simple
User=pi
WorkingDirectory=/home/pi/dish-tracker
ExecStart=/usr/bin/python3 /home/pi/dish-tracker/server.py
Restart=always
RestartSec=3
Environment=PORT=8080

[Install]
WantedBy=multi-user.target
```

Активируйте и запустите службу:
```bash
# Перечитываем конфигурацию systemd
sudo systemctl daemon-reload

# Включаем автозапуск при старте системы
sudo systemctl enable dish-tracker

# Запускаем службу
sudo systemctl start dish-tracker

# Проверяем статус работы
sudo systemctl status dish-tracker
```

#### Полезные команды управления:
```bash
# Просмотр живого лога сервера
journalctl -u dish-tracker -f

# Перезапуск службы
sudo systemctl restart dish-tracker

# Остановка службы
sudo systemctl stop dish-tracker
```

### 🌟 Вариант А: Firebase Realtime Database (Самый простой, бесплатно)

Идеальный выбор: не требует белого IP-адреса, настройки роутера или постоянно включенного компьютера.

1. Откройте [Google Firebase Console](https://console.firebase.google.com/) под своим Google-аккаунтом.
2. Нажмите **«Создать проект»** (назовите его, например, `dish-tracker`).
3. В боковом меню откройте **«Сборка» (Build)** ➔ **«Realtime Database»** и нажмите **«Создать базу данных»**.
4. Выберите ближайший регион (например, *Belgium / europe-west1*).
5. Перейдите во вкладку **«Правила» (Rules)** и вставьте:
   ```json
   {
     "rules": {
       ".read": true,
       ".write": true
     }
   }
   ```
   Нажмите **«Опубликовать» (Publish)**.
6. В верхней части вкладки «Данные» скопируйте URL созданной базы:
   ```text
   https://ваш-проект-default-rtdb.europe-west1.firebasedatabase.app/
   ```
7. Откройте **Чистую Тарелку**, перейдите в **«Настройки» (☰)**, вставьте скопированный адрес в поле **«Облачная синхронизация»** и сохраните.

*Статус в шапке изменится на «В облаке 🟢», и все смартфоны будут синхронизироваться моментально.*

### ⚡ Вариант Б: Cloudflare Workers + KV (Быстро и без ограничений)

Надежное бессерверное решение. Cloudflare предоставляет 100 000 бесплатных запросов каждый день.

В репозитории уже готовы файлы:
- `cloudflare-worker.js` / `worker.js`
- `wrangler.toml`

#### Развертывание через панель Cloudflare:
1. Зарегистрируйтесь бесплатно на [cloudflare.com](https://cloudflare.com).
2. В боковом меню откройте **«Workers & Pages»** ➔ **«Create application»** ➔ **«Create Worker»**.
3. Назовите воркер (например, `dish-sync`) и нажмите **«Deploy»**.
4. Нажмите **«Edit code»**, замените шаблон кодом файла [`cloudflare-worker.js`](cloudflare-worker.js) и нажмите **«Deploy»**.
5. Вернитесь в настройки воркера ➔ вкладка **«Settings»** ➔ **«Variables»** ➔ раздел **«KV Namespace Bindings»**.
6. Создайте хранилище KV с именем `DISH_KV` и привяжите его к переменной `DISH_KV`.
7. Скопируйте адрес воркера (`https://dish-sync.ваш-аккаунт.workers.dev`) и укажите его в настройках трекера.

### 🛡️ Вариант В: Доступ к домашнему серверу через Cloudflare Tunnel

Если трекер крутится дома на Raspberry Pi, и вы хотите открывать его по личному домену с бесплатным HTTPS:

1. Установите агент на Raspberry Pi:
   ```bash
   curl -L --output cloudflared.deb https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-arm64.deb
   sudo dpkg -i cloudflared.deb
   ```
2. Авторизуйтесь в Cloudflare:
   ```bash
   cloudflared tunnel login
   ```
3. Создайте постоянный туннель к порту 8080:
   ```bash
   cloudflared tunnel create dish-tunnel
   cloudflared tunnel route dns dish-tunnel dishes.yourdomain.com
   cloudflared tunnel run --url http://localhost:8080 dish-tunnel
   ```
4. Сервер доступен по адресу `https://dishes.yourdomain.com` без белого IP и без проброса портов на роутере.

### 🔒 Вариант Г: Приватная Mesh-сеть через Tailscale (WireGuard)

Самый безопасный домашний вариант: шифрует трафик, не светит сервер наружу и не требует домена.

1. **На сервере (Raspberry Pi / Linux):**
   ```bash
   curl -fsSL https://tailscale.com/install.sh | sh
   sudo tailscale up
   ```
2. **На смартфонах участников:**
   - Установите приложение **Tailscale** ([iOS App Store](https://apps.apple.com/app/tailscale/id1470499037) / [Google Play](https://play.google.com/store/apps/details?id=com.tailscale.ipn)).
   - Войдите под тем же аккаунтом.
3. **Готово:** открывайте трекер прямо по короткому имени сервера в сети MagicDNS (например, `http://dish-pi:8080`) или по Tailscale IP (`http://100.x.y.z:8080`).

### ⚡ Вариант Д: Экспресс-доступ через Ngrok (за 30 секунд)

Быстрый способ временно пробросить локальный сервер в интернет для теста:

1. Установите Ngrok:
   - **Linux / Raspberry Pi**:
     ```bash
     curl -s https://ngrok-agent.s3.amazonaws.com/ngrok.asc | sudo tee /etc/apt/trusted.gpg.d/ngrok.asc >/dev/null
     echo "deb https://ngrok-agent.s3.amazonaws.com buster main" | sudo tee /etc/apt/sources.list.d/ngrok.list
     sudo apt update && sudo apt install ngrok
     ```
   - **macOS**: `brew install ngrok/ngrok/ngrok`
2. Авторизуйте токен с [ngrok.com](https://ngrok.com):
   ```bash
   ngrok config add-authtoken ВАШ_ТОКЕН
   ```
3. Запустите туннель к порту 8080:
   ```bash
   ngrok http 8080
   ```
   Ngrok выдаст ссылку вида `https://xxxx.ngrok-free.app`, которую можно сразу открыть на телефоне.

## 🔌 Справочник REST API

Сервер предоставляет лаконичный и быстрый HTTP API:

| Метод | Путь | Назначение | Особенности |
|:---:|:---|:---|:---|
| `GET` | `/api/state` | Текущее состояние приложения | Поддерживает заголовок `If-None-Match` и возвращает `304 Not Modified` при отсутствии изменений |
| `GET` | `/api/version` | Проверка версии состояния (легковесный опрос) | Возвращает компактный JSON (версия и ETag) |
| `POST` | `/api/login` | Проверка учетных данных пользователя | Возвращает сессионный SHA-256 токен |
| `POST` | `/api/state` | Сохранение состояния (мойка, смена, реакция) | Требует заголовки авторизации `X-Auth-User` и `X-Auth-Token` |
| `GET` | `/api/events` | Потоковые обновления в реальном времени (SSE) | Доступно в версии на Node.js (`server.js`) |

## 🛠️ Разработка и локальная проверка

```bash
# Клонируйте репозиторий
git clone https://github.com/ваш-логин/dish-tracker.git
cd dish-tracker

# Запустите сервер на Python 3
python3 server.py
```

Откройте [http://localhost:8080](http://localhost:8080) в браузере.

### Проверка офлайн-режима:
1. Откройте инструменты разработчика браузера (F12 или `Cmd+Option+I` ➔ вкладка *Application* ➔ *Service Workers*).
2. Поставьте галочку **Offline**.
3. Обновите страницу — приложение мгновенно загрузится из кэша.
