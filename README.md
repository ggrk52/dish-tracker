# 🍽️ Чистая Тарелка 2.0 — График и Журнал мытья посуды

Семейный трекер дежурств по кухне для: **Мама**, **Папа**, **Серёжа** и **Вася**.

---

## 🌟 Что нового в версии 2.0:

1. **🎨 Новый современный дизайн (Apple iOS style):**
   - Удобная нижняя панель навигации по разделам (**Дежурство**, **История**, **Почёт**, **Облако**).
   - Glassmorphism-эффекты, плавные анимации, адаптация под телефоны, планшеты и компьютеры.
   - Тёмная и светлая темы.

2. **📜 Богатая и надежная история:**
   - Каждая помывка сохраняется навсегда: точная дата, время и сколько длилась смена.
   - **Группировка по дням** («Сегодня», «Вчера», «19 октября»...).
   - **Фильтры**: можно в один клик отфильтровать помывки конкретного человека (только Мама, только Серёжа и т.д.).
   - **Семейные реакции (❤️, 👏, 🌟)**: родные могут нажимать на сердечко или хлопки, чтобы похвалить того, кто помыл посуду!
   - **Экспорт в CSV / Excel**: кнопка «Скачать» выгружает всю историю в табличку.

3. **🏆 Доска почёта и номинации:**
   - «Гроза сковородок» — лидер по числу моек.
   - «Любимчик кухни» — кто собрал больше всего сердечек ❤️.
   - Процентный вклад каждого члена семьи.

4. **☁️ Работа в интернете без локального компьютера:**
   - Встроена прямая поддержка **Firebase Realtime Database** (бесплатная база от Google).
   - Готовы файлы для бесплатного размещения на **Vercel** или **GitHub Pages**.

## 🌐 Как выложить приложение в интернет (бесплатно)

### Вариант 1: Vercel (Самый легкий, 2 минуты)
1. Зарегистрируйтесь бесплатно на [vercel.com](https://vercel.com) (можно войти через Google или GitHub).
2. Установите Vercel CLI (или просто подключите папку через GitHub):
   ```bash
   npx vercel
   ```
3. Вы получите постоянную ссылку вида: `https://chistaya-tarelka.vercel.app`, которая доступна всем родным круглосуточно с любого мобильного интернета.

### Вариант 2: GitHub Pages (100% бесплатно)
1. Создайте репозиторий на GitHub.
2. Загрузите файлы из папки `dish-tracker`.
3. В настройках репозитория (*Settings ➔ Pages*) выберите ветку `main` и нажмите **Save**.
4. Ссылка будет вида: `https://ваш-логин.github.io/dish-tracker/`.

## ☁️ Как подключить облачную синхронизацию (Firebase)

Чтобы любые изменения на телефоне Серёжи моментально отображались у Мамы и Папы через интернет:

1. Зайдите на [console.firebase.google.com](https://console.firebase.google.com) под Google-аккаунтом.
2. Нажмите **«Создать проект»** (назовите, например, `family-dishes`).
3. В левом меню откройте **«Build» ➔ «Realtime Database»** и нажмите **«Создать базу данных»**.
4. Во вкладке **«Правила»** (Rules) вставьте:
   ```json
   {
     "rules": {
       ".read": true,
       ".write": true
     }
   }
   ```
5. Скопируйте URL вашей базы (например: `https://family-dishes-default-rtdb.firebaseio.com/`).
6. В приложении перейдите во вкладку **«Облако»**, вставьте этот URL и нажмите **«Сохранить»**.

Готово! Теперь статус станет **«В облаке 🟢»**, и все устройства семьи будут синхронизироваться по всему миру без единого сервера.
